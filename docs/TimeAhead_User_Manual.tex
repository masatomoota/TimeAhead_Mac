\sectionbar{TimeTealDark}{1. TimeAhead の役割}

\noindent
\infocard{TimeTealDark}{white}{一言でいうと}{
TimeAhead は、通常の時計とは別に「今から何分進めた時刻か」をメニューバーへ表示する小さな常駐アプリです。
会議・配信・締切・タイムキープなどで、実際のシステム時刻を変えずに先読み時間を確認できます。
}

\sectionbar{TimeYellow!80!black}{4. インストールと起動}

\begin{enumerate}
  \item Finder で \texttt{build/TimeAhead.app} を確認します。
  \item 通常利用する場合は \texttt{/Applications} にコピーして起動します。
  \item 初回起動時に Gatekeeper の警告が出る場合は、右クリックして「開く」を選びます。
  \item 起動後、メニューバー右側にオフセット時刻が表示されることを確認します。
\end{enumerate}

\sectionbar{TimeCoral}{6. 注意点}

\begin{itemize}
  \item TimeAhead はシステム時刻を変更しません。標準時計とは別に、追加のオフセット時計を表示します。
  \item 標準の macOS 時計を完全に置き換える機能はありません。
  \item \texttt{build/} は Git 管理対象外です。配布前に必ず再ビルドしてください。
  \item Developer ID 署名や notarization は未設定です。外部配布時は追加の署名・公証作業が必要です。
  \item 現在の成果物は Apple Silicon / \texttt{arm64} 向けに検証されています。
\end{itemize}
